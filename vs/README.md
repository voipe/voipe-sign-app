# VoIPe Sign — fork of Documenso

This repository is VoIPe's modified build of [Documenso](https://github.com/documenso/documenso) (AGPL-3.0),
served at https://sign.voipe.co.il. It is published to comply with AGPL-3.0 §13.

- Base: upstream tag `v2.21.1`, branch `vs/main`. Our changes are small commits on top (Hebrew locale + RTL, branding).
- Image: `ghcr.io/voipe/voipe-sign-app:<version>` (see `vs/VERSION`).
- All original copyright and license notices are retained. License: AGPL-3.0 (see `LICENSE`).

Fork documentation: `vs/TRANSLATION.md` (Hebrew catalog, coverage, QA notes), `vs/BRANDING.md` (vendor branding), `vs/LEGAL.md` (AGPL checklist), `vs/tools/` (catalog validator and sync scripts).
